# Credits — Space Invaders remake

## The original game
- **Space Invaders** © 1978 Taito Corporation, designed by Tomohiro Nishikado. Space Invaders is a
  trademark of Taito. The graphics (sprites, font) and the game design belong to Taito; this is an
  unofficial, non-commercial fan remake (CC BY-NC-SA, see LICENSE).
- The ROM set `invaders` (Midway licence, hardware-identical) is **not** part of this repository.
  It is used only as the local source for `tools/rom2sprites.spec.json` and the reference emulator.

## Data derived from the ROM (in `data/`)
- `data/sprites.json`, `data/font.json` — generated by `tools/rom2sprites` from the ROM
  (addresses 1BA0–1FFF, see the `source` field of every object). The extraction tool is ours, the
  pixel art is Taito's.

## Documentation and reference material used (in `sources/`, outside git)
- **Computer Archeology — Space Invaders** (`invaders.asm`, `Code.txt`, `RAMUse.txt`, `Hardware.txt`):
  annotated disassembly by Chris Cantrell et al., https://computerarcheology.com/Arcade/SpaceInvaders/.
  Source of the game logic, tables and coordinates cited in `GAME-DESIGN.md` chap. 2.
- **MAME** drivers `mw8080bw`, `8080bw`, `sn76477` (GPL-2.0+/BSD-3, see `sources/mame/COPYING`):
  timing, interrupts, overlay geometry (`invaders.lay`, CC0-1.0).
- **valleyco/invaders** (GPL): its Intel 8080 core (`8080/src/emu-8080.c`) is linked by our headless
  reference emulator `tools/refemu` (dev tool only, replaces MAME for snapshots and RAM traces;
  nothing of it is used by the game).
- Texas Instruments SN76477 datasheets; Taito/Midway manuals and schematics (sound synthesis, SI-M7).
